# 市场热度与情绪指标全解 · A 股

A 股市场情绪驱动显著，资金面 / 情绪面指标往往比基本面更早给出拐点信号。本文覆盖**个股、板块、大盘**三层的情绪指标。

## 一、个股层面

### 1. 成交与换手

| 指标 | 计算 | 解读 |
| --- | --- | --- |
| 换手率 | 成交量 / 流通股本 | 超过 20 日均值 2 倍 = 放量 |
| 量比 | 当日分钟均量 / 过去 5 日同时段分钟均量 | >2 放量，<0.5 缩量 |
| 成交额占比 | 个股成交 / 市场成交 | 主力关注度变化 |

### 2. 资金流（逐笔单推算）

- **超大单**：单笔 ≥ 100 万或 500 万（各家定义不一，东财是 100 万）。
- **大单**：20 万~100 万。
- **中单**：4 万~20 万。
- **小单**：< 4 万。

关键组合：
- 超大单 + 大单 = 主力净流入。
- 连续 3 日主力净流入 + 股价上涨 = 吸筹。
- 连续 3 日主力净流入 + 股价不涨 = 护盘 / 对倒嫌疑。
- **⚠️ 这是撮合推算，不是席位真实买卖，只能当情绪参考。**

### 3. 龙虎榜（真实席位）

- 达标条件：日涨跌幅偏离值 ±7%、振幅 15%、换手率 20%、连板次数。
- 席位类型：
  - **机构专用**：公募 / 社保 / 保险 / QFII。
  - **知名营业部**："拉萨某营业部"= 东财一账户（散户合流），"深股通专用"= 北向。
  - **游资席位**：如"方新侠"、"章盟主"等。
- 研判：
  - 一家机构买入 + 多家游资卖出 = 可能筹码换手到长线资金。
  - 五家游资混战 = 纯情绪炒作，接力风险高。

### 4. 融资融券

- **融资余额 / 流通市值**：>5% 是高杠杆票。
- **融资买入额 / 成交额**：>15% 意味着当天涨是借钱买出来的。
- **融券余量**：A 股融券成本高、规模小，参考价值弱。

### 5. 北向资金（陆股通）

- 持股市值 / 自由流通市值：持仓占比越高，话语权越强。
- 月度净买入方向 vs 股价：背离是重要信号。
- **⚠️ 2024 年起官方不再实时披露，改为每日收盘后一次性披露；分析时注意数据延迟。**

### 6. 机构调研

- 近 3 个月接待调研机构数、私募 vs 公募 vs 外资比例。
- 调研纪要中的核心问题 = 市场担忧点。
- akshare：`ak.stock_jgdy_tj_em()`、`ak.stock_jgdy_detail_em()`。

## 二、板块层面

### 1. 板块热度温度计

- **板块换手率** vs 自身 20 日均值。
- **板块成交额占全市场比例**：>10% 是明显热点。
- **板块主力净流入连续性**：连续 3 日同向 > 单日峰值。
- **涨停板集中度**：板块内当日涨停 ≥ 3 家 = 资金扎堆。

### 2. 概念板块 vs 行业板块

- **行业板块**（申万 / 东财行业）：成分固定，估值有意义。
- **概念板块**（同花顺 / 东财概念）：成分可变、重叠大，估值不可直接比。
- 判断纯炒作 vs 基本面：
  - 题材 → 行业 → 个股业绩：如果只停在题材，业绩未兑现，是纯情绪。
  - 典型"主题投资生命周期"：事件催化 → 题材普涨 → 龙头分化 → 基本面验证 → 证伪 / 兑现。

### 3. 轮动信号

- 上游涨 + 下游不涨：通胀 / 成本传导滞后。
- 周期领涨 → 消费领涨 → 金融领涨：常规牛市节奏。
- 防御板块领涨（公用 / 医药 / 高股息）：避险情绪。

## 三、大盘 / 全市场层面

### 1. 量能

- 两市日成交额：
  - < 6000 亿 = 冰点。
  - 6000~9000 亿 = 存量博弈。
  - 9000 亿~1.2 万亿 = 结构牛。
  - > 1.5 万亿 = 全面牛市 / 疯牛。
- 沪深 300 成交占全市场比例：>40% 价值风格，<30% 小盘风格。

### 2. 涨跌家数结构

- 涨停家数 - 跌停家数：>50 强势，< -30 弱势。
- 连板高度（最高几板）：反映情绪天花板。
- 炸板率 = 炸板数 / (涨停数 + 炸板数)：>40% 情绪退潮。
- 赚钱效应 = 当日涨 5% 以上家数 / 跌 5% 以上家数。
- 亏钱效应阈值：跌 5% 家数 > 500 是恐慌日。

### 3. 估值与风险溢价

- 全 A PE-TTM 历史分位数（近 10 年）。
- 全 A 风险溢价 = 1/PE − 10Y 国债收益率，>5% 股票便宜，<2% 股票贵。
- 股债性价比（FED 模型）指标。
- 破净股数量 / 上市公司数量：>10% 是极端底部信号。
- 创 60 日新高 vs 创 60 日新低家数比值。

### 4. 杠杆与资金供给

- 两融余额绝对值 + 占流通市值比值。
- 新发基金份额（月度）：>1000 亿 = 增量资金时代。
- 基金仓位（股票型、混合型）：> 88% 接近满仓。
- ETF 申赎：宽基 ETF 连续净申购 = 增量资金入场。

### 5. 情绪指标（A 股特色）

- 涨跌停比率
- **新股破发率**：一级市场情绪传导。
- 可转债溢价率中位数：>30% 是疯狂，<5% 是冰点。
- 北交所 / 科创板 / 创业板 / 主板 成交比例：小盘活跃度。
- 股指期货基差（IC / IH / IF / IM）：远月贴水越深，对冲需求越强。

## 四、评分方法（示例）

给"热度卡"打分时建议用下表加权：

| 维度 | 权重 | 满分判定 |
| --- | --- | --- |
| 个股换手与量能 | 20% | 放量上涨趋势中 |
| 主力资金方向 | 15% | 连续 3 日净流入 |
| 龙虎榜席位性质 | 15% | 机构占优 |
| 北向态度 | 15% | 季度持仓增加 |
| 融资余额趋势 | 10% | 同向温和增加 |
| 所处板块热度 | 15% | 板块热度前 10 |
| 市场整体情绪 | 10% | 大盘赚钱效应 > 1 |

得分 ≥ 80：高热度，注意追高风险；
60~80：温和关注；
< 60：冷门，可能是价值陷阱也可能是被错杀。

## 五、误用警告

- ❌ 把"主力净流入"反推"机构买入"——实际是分价带统计，不分资金性质。
- ❌ 用分钟级资金流做短期预测——噪声远大于信号。
- ❌ 把"北向买入"等同于"外资长线配置"——其中混有对冲基金、量化、内资借道。
- ❌ 用单日龙虎榜判断趋势——看连续性。
- ❌ 忽视停牌复牌、除权除息日对换手率 / 涨跌幅的扰动。
