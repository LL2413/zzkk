# 基本面完整清单 · 公司盈利发展

一份用于 A 股个股的深度基本面核查清单。建议按顺序打勾，不要跳步。

## A. 前置检查

- [ ] 股票是否为 ST / *ST / 退市整理期？若是，停止常规分析，改用"困境股"框架。
- [ ] 是否最近 12 个月内有重大重组、借壳、剥离？若是，合并报表可比性大打折扣。
- [ ] 会计准则是否发生切换（新收入准则 / 新租赁准则等）？若是，同比口径要重算。
- [ ] 审计意见是否"标准无保留"？非标意见要标红。
- [ ] 是否被立案调查、处罚、问询函未回复？

## B. 盈利规模与质量（Quality of Earnings）

### 营收与利润

- [ ] 最近 8 个季度的 **营业收入、归母净利润、扣非净利润** 走势。
- [ ] **扣非占归母比例**：长期 < 80% 需要警惕非经常性损益。
- [ ] **营收增速 vs 净利润增速**：两者背离要找原因（费用、折旧、税率、投资收益）。
- [ ] **前五大客户占比 / 前五大供应商占比**：集中度过高（>50%）是风险。
- [ ] **分地区 / 分产品收入构成**：核心业务是哪块？是否在萎缩？

### 毛利 / 净利

- [ ] 毛利率是否稳定？毛利率走低的原因（原材料 / 价格战 / 产能利用率）？
- [ ] 净利率 vs 毛利率的差：期间费用率（销售 / 管理 / 研发 / 财务）。
- [ ] 研发费用率：科技类公司 < 5% 要质疑，消费类 < 2% 是常态。

### ROE 杜邦拆解

```
ROE = 净利率 × 总资产周转率 × 权益乘数
```

- [ ] 三个驱动因子近 5 年的变化方向。
- [ ] ROE 上升是"真实经营改善（净利率 / 周转率↑）"还是"加杠杆（权益乘数↑）"？
- [ ] ROIC（投入资本回报率）是否 > 加权资金成本？区分"烧钱增长" vs "赚钱增长"。

## C. 现金流

- [ ] 经营性现金流 / 归母净利润：近 3 年是否 ≥ 0.8？
- [ ] 经营性现金流是否 > 0？连续多年 < 0 要警惕"纸面利润"。
- [ ] 资本开支（Capex）/ 折旧摊销：>1 是扩张期，<1 是收缩期。
- [ ] 自由现金流 = 经营现金流 − Capex：FCF 为正的公司才谈得上高质量。
- [ ] 应收账款周转天数、存货周转天数：变化方向是否匹配营收？

## D. 资产负债表健康度

- [ ] 资产负债率：重资产行业 <60%，轻资产 <40%。
- [ ] 有息负债 / 净资产：>1 是高杠杆。
- [ ] 短期借款 vs 货币资金：短债覆盖比 < 1 的公司有流动性风险。
- [ ] **商誉 / 净资产**：>30% 要逐笔看商誉来源的子公司业绩承诺。
- [ ] 应收账款 + 合同资产 增速 vs 营收增速：前者显著更快意味着放宽信用。
- [ ] 存货跌价准备、应收账款坏账准备计提是否与同行一致。

## E. 估值与分红

### 估值

- [ ] PE-TTM、PB-MRQ、PS-TTM、EV/EBITDA、PEG。
- [ ] 每个估值指标的 **5 年分位数** 与 **10 年分位数**。
- [ ] 同行业 5 家可比公司的估值对比表（均值、中位数）。
- [ ] 如果是周期股：用 **PB × ROE 历史中枢** 而不是 PE。
- [ ] 如果是成长股：关注 PEG < 1 是否有持续性，而非 PE 本身。
- [ ] 如果是金融股：用 PB + ROE，或 P/PPOP。

### 分红

- [ ] 近 5 年股利支付率（分红 / 归母净利润）。
- [ ] 股息率（TTM 现金分红 / 市值）。
- [ ] 是否为"中特估"标的、"红利低波"指数成份？

## F. 治理与股东结构

- [ ] 控股股东、实控人：是否央企 / 地方国企 / 民企 / 外资。
- [ ] 控股股东质押比例：>70% 有爆仓风险。
- [ ] 近 12 个月高管、大股东 **减持 / 增持** 记录。
- [ ] 股权激励：行权价、业绩考核条件是否合理。
- [ ] 近 3 年重大关联交易金额与定价。

## G. 行业地位

- [ ] 市占率（营收 / 产量 / 出货量口径）。
- [ ] 近 3 年市占率的变化方向。
- [ ] 技术指标：专利数、研发管线、产能规划。
- [ ] 护城河类型：品牌、规模、网络效应、转换成本、政策牌照、技术壁垒。

## H. 关键风险清单

- [ ] **业绩变脸**：一季报 / 中报是否低于预期或预告下修。
- [ ] **解禁**：未来 6 个月是否有大额限售股解禁。
- [ ] **商誉暴雷**：被收购子公司是否未完成业绩承诺。
- [ ] **监管**：是否涉及反垄断、数据安全、行业集采、双碳等政策冲击。
- [ ] **诉讼与合规**：未决诉讼金额 / 净资产。
- [ ] **审计 / 换所**：频繁更换会计师事务所是警报。
